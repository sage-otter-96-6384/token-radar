Token launch radar: ranks pre-token DeFi protocols by implied value, with concrete farm plans for each. The value model derives implied value from the snapshot's own figures — TVL, seven-day growth and how long a protocol has run with no token — never from a hardcoded list of names. The board covers all 40 watchlist protocols plus 138 early ones below the floor, and the dashboard is a static page with a sortable board, a detail view per protocol and filters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
